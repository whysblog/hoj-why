黑白方块图 ↔ 0/1 编码

用 0 表示白色,用 1 表示黑色,你设计的图案就能变成一串数字编码!画的越复杂,编码就越长。

🔍 玩法提示: 在左侧网格中点击方块切换黑白(也可以拖动鼠标快速绘制),右侧的 0/1 编码会立即更新。 或者反过来在右侧输入 0 和 1,左侧的图案会自动出现!试着对比 4×4 和 8×8 网格,看看编码长度有什么不同?
