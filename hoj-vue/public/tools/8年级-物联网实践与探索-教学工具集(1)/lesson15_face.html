三、关键技术与挑战

🧠 特征向量（Embedding）

训练好的深度学习模型会把每张人脸转换为一个固定长度的数字向量（如 128 或 512 维）。同一个人不同角度/光照下的脸，向量距离很近；不同人则距离远。

  • 每张人脸 → 一串数字（"指纹"）
  • 相似度 = 1 - 向量间距离
  • 注册：保存向量到数据库

👁 活体检测

仅凭 2D 摄像头容易被照片或视频欺骗。为防止这种攻击，会增加活体检测：

  • 红外活体：红外摄像头看体温/3D 深度
  • 动作活体：要求用户眨眼、转头
  • 纹理活体：区分屏幕反光和皮肤

⚖ 相似度 vs 阈值

阈值设置是安全与便利的平衡。阈值越高越安全但可能识别失败；越低越好用但可能误识别。

  • 家用门锁：阈值约 0.85
  • 银行支付：阈值约 0.95+
  • 评估指标：FAR（误识率）和 FRR（拒识率）

🔒 隐私保护

人脸数据涉及强隐私，必须妥善保护：

  • 原始图像不上传云端，本地特征化
  • 特征向量加密存储，不可还原
  • 注销账户时彻底删除所有特征
  • 遵守《个人信息保护法》
