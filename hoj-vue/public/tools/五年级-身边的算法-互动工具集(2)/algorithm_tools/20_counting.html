🐍 Python 代码

# 设置计数变量的初值
c = 1

# 用循环控制从 1 数到 100
while c <= 100:
    print(c)       # 输出当前的数
    c = c + 1   # 计数变量加 1
🔑 三要素:
  • 初始化: c = 1
  • 判断条件: c ≤ 100
  • 循环体: 输出 c 并 c = c + 1

5循环的强大之处

🚀 速度快

普通个人计算机,1 秒能枚举几百万个数。同样的任务人需要几小时甚至几天。

🔁 不厌其烦

从 1 数到 1 亿,计算机不嫌烦不出错,人却很难做到。

🎯 准确可靠

只要程序写对,计算机执行 100 万次都不会出错。
