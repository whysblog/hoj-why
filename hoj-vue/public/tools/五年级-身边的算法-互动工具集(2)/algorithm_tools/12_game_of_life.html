📚 关于生命游戏: 数学家约翰·康威 1970 年发明的细胞自动机。每个格子代表一个"细胞",有"存活"和"死亡"两种状态。仅靠两条简单规则,就能演化出令人惊叹的复杂图案——这正是"涌现"现象的经典案例。

存活规则
活细胞周围有 2 或 3 个活细胞 → 下一代继续存活
3
死亡规则
活细胞周围 少于 2 个(孤独)或 多于 3 个(拥挤)活细胞 → 下一代死亡

🔬 生命游戏的科学意义

"涌现"现象:仅 3 条简单规则,产生了振荡器、移动飞船、稳定结构等丰富图案。这说明简单规则可以产生复杂行为——大自然中的雪花、蚁群、心跳节律、市场波动都遵循类似机制。

图灵完备:数学家证明,生命游戏可以模拟任何计算机程序——理论上,你能在它的网格里"搭建"出一台计算机!

它还告诉我们什么?

  • 算法不必复杂——少数关键规则就能创造无限可能
  • 初始条件很重要——细微差别会导致完全不同的演化
  • 计算机能够模拟世界——这正是科学计算和人工智能的基础
