凯撒密码：把明文中的每个字母按一定规则向后移动几位生成密文。例如向右移动3位时，A→D，B→E，依此类推；如果超过Z就回到字母表开头继续移位。

📚 算法小知识

历史故事：凯撒密码因古罗马军事家凯撒大帝在战争中使用而得名。当年它保护了重要的军情信息。

算法步骤（自然语言描述）：

  • 第1步：输入要传送的明文。
  • 第2步：取一个字母，将它向右移动指定位数，并输出对应的密文字母。
  • 第3步：重复第2步，直到处理完所有字母。

这是一个典型的循环结构算法。解密只需把"向右移动"改为"向左移动"即可。

⚠️ 安全性思考：移位密码只有26种可能（移位1~25加移位0），现代计算机可在瞬间破解，因此早已不能直接用于保护重要信息。但它的思想被融入到许多现代加密方法中。
