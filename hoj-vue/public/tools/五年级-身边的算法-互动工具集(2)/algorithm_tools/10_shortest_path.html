动态规划思想：把"求起点到终点的最短路径"这个大问题，分解为"求起点到每个中间点的最短用时"这些小问题。

核心公式：到达 (i, j) 的最短用时 = min(从上方来, 从左方来) + 该格本身的"代价"

  • 从上方来：上方的最短用时 + 上方到该点的边权重
  • 从左方来：左方的最短用时 + 左方到该点的边权重
  • 两者取较小值

对比两种算法：

  • 📋 枚举法：列出所有可能的路径，计算时间，找出最短的。简单但路径数会随着地图增大爆炸式增长。
  • ⚡ 动态规划：每个点的最短用时只计算一次并保存，避免重复计算。效率非常高。

实际应用：导航软件查找最快路线、物流配送规划、网络数据包路由、机器人路径规划等。
