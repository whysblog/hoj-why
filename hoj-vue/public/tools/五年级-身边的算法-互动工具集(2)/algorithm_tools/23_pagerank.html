5⚙️ PageRank 算法模拟
100 个访问者随机游走,看最后在哪个网页"扎堆"
迭代次数: 0 / 共 100 个访问者
📘 PageRank 的核心思想:
  • 初始把访问者平均分配到各网页
  • 每个访问者按当前页的链接随机跳转到下一页
  • 多次迭代后,有的网页会"沉淀"更多访问者 → 排名更高
6本课小结
🌟 你今天学到了:
  • 简单的排名算法:数被链接次数
  • PageRank算法:用"投票"和"随机游走"判断网页重要性
  • 搜索引擎给出的排名,背后藏着精巧的算法
  • 实际中还会考虑:链接强度、链接来源质量等多种因素
