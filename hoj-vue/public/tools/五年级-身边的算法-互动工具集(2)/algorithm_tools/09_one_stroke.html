历史故事：1736 年，欧拉解决了著名的"哥尼斯堡七桥问题"——能不能不重复地走过城里的 7 座桥？欧拉将岛和岸抽象为点，把桥抽象为边，发明了图论。

欧拉判定定理：一个连通图能否一笔画出，看奇点的数量：

  • ✅ 0 个奇点：可以一笔画，起点和终点是同一个点（欧拉回路）
  • ✅ 2 个奇点：可以一笔画，从其中一个奇点出发到另一个奇点（欧拉路径）
  • ❌ 其他情况：不能一笔画

为什么？除了起点和终点，每经过一个点都是"进入1次+离开1次"，所以中间点连接的边数必须是偶数。

实际应用：邮递员路线规划、城市道路规划、电路布线设计等场景都用到一笔画的思想。
