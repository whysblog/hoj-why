📚 算法小知识

枚举法（暴力破解）：逐一尝试所有可能的组合，直到找到正确答案。这是一种"笨办法"，但因为计算机运算速度快，对于简单密码非常有效。

组合数计算：每位字符的可能种类数 × 密码长度个相乘。

  • 4位纯数字：10⁴ = 10,000 种
  • 6位"数字+字母"：62⁶ ≈ 568亿 种
  • 6位"数字+字母+符号"：94⁶ ≈ 6900亿 种

设置安全密码的原则：

  • 足够的长度（至少8位以上）
  • 包含大小写字母、数字和符号
  • 不使用姓名、生日、电话号码等
  • 不同的网站/账号使用不同的密码
