📚 算法小知识

二分法的核心思想：每次都把查找范围分成两半，根据比较结果选择目标数所在的那一半，迅速缩小范围。

算法步骤：

  • 第1步：取中间位置的数与目标数比较，相等则查找成功。
  • 第2步：如果中间数大于目标数，就在前半部分继续查找；否则在后半部分查找。
  • 第3步：重复以上两步，直到找到答案。

实际应用：查找监控视频中的事件、字典查单词、找通讯录联系人等都可以用二分法。
