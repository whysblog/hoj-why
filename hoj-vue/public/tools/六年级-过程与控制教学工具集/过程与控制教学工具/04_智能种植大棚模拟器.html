湿度: 60%
光照: 50000 lx
温度: 22°C
状态: 良好

💧 土壤湿度控制系统

输入：湿度 → 计算：与阈值比较 → 输出：喷灌器
喷灌器：待机
湿度(60) > 阈值(40) → 真值表：1 → 不喷水

☀️ 光照控制系统

输入：光照 → 计算：与阈值比较 → 输出：补光灯
补光灯：关闭
光照(50000) > 阈值(30000) → 真值表：0 → 不补光

🌡️ 温度控制系统

输入：温度 → 计算：与阈值比较 → 输出：暖风机
暖风机：停止
温度(22) > 阈值(15) → 真值表：0 → 不加热
💡 实验玩法： 拖动各传感器的滑块改变环境数据，观察大棚里设备状态的变化。

🔬 科学原理： 每个子系统都是一个闭环控制系统。传感器把连续量数据（湿度%、光照lx、温度°C）和阈值比较，再生成开关量指令（1=启动，0=停止）控制输出设备。

🎯 试一试： 把湿度调到 30%（低于阈值40%）→ 喷灌器启动；把温度调到 5°C（低于阈值15°C）→ 暖风机启动；把光照调到 10000 lx（低于阈值30000 lx）→ 补光灯打开。
