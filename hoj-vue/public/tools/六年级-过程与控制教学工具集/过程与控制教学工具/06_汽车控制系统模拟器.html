汽车控制系统模拟器 🚗

体验汽车中的四个控制子系统：转向灯、安全带、倒车防撞、定速巡航

自动熄灭转向灯系统

驾驶员转动方向盘超过 30° 时，转向灯亮起；完成转弯回转方向盘时，转向灯自动熄灭。如果方向盘转动角度不足30°（如变换车道），需要手动关闭。

📊 工作流程：方向盘角度 → 与阈值30°比较 → 判断是否回转 → 控制转向灯
方向盘角度：0°
状态：转向灯熄灭。请操控方向盘观察变化。
算法流程：
if 角度 > 阈值 then 灯亮
if 灯亮 且 回转方向盘 then 自动熄灭

安全带未系提醒系统

通过座椅压力传感器检测是否有人，通过微动开关检测安全带是否系好。如果有人但未系安全带，仪表盘警示灯闪烁，发出语音提醒。

📊 工作流程：座椅传感器 + 安全带传感器 → 与运算 → 警报输出

倒车防撞警报系统

超声波传感器检测车与障碍物的距离。距离越近，警报频率越高，提示驾驶员越紧迫。

📊 距离计算规则（基于教材第113页）：1.5-1m → 1声/2秒 ；1-0.6m → 1声/1秒 ；0.6-0.3m → 1声/0.5秒

定速巡航控制系统

设定目标车速后，系统持续检测当前车速，如果低于阈值就加速，高于阈值就减速。这是一个典型的闭环控制系统。

📊 闭环结构：设定车速（阈值）→ 比较当前车速 → 调整 → 反馈检测 → 持续调整…
