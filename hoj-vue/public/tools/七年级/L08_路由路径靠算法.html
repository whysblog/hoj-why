什么是路由？

📦 核心问题：当你的数据包要从北京去上海，互联网上有千千万万条线路，该走哪条？

路由 (Routing) 就是为数据包选择最佳传输路径的过程。这个工作由路由器 (Router)完成。

🚦 类比：城市交通

  • 数据包 = 一辆从家开往学校的汽车
  • 路由器 = 路口的交通指挥员
  • 路由表 = 指挥员的"地图册"，告诉他每个目的地该往哪个方向走
  • 路由算法 = 怎么选择最佳路线（最短？最快？避开堵车？）

路由器在哪里？

🏠
家庭路由器
家里的小白盒子，把你家几台设备连接到互联网。
🏢
企业路由器
公司、学校用，连接的设备多，性能更强。
🌍
运营商核心路由器
中国移动、电信、联通的骨干路由器，每秒处理数 TB 流量。
🛰
国际出口路由器
连接中国和外国的关键节点，全国只有少数几个。
🌐 整个互联网，就是由数百万台路由器组成的"包裹中转站网络"。每个数据包要经过几跳、几十跳路由器才能到达目的地。

路由表 (Routing Table)

每台路由器都保存一张"路由表"——记录着到各个目的网络要从哪个出口走。

目的网络下一跳 (Next Hop)出口接口跳数
192.168.1.0/24直接连接eth00
10.0.0.0/8192.168.1.1eth01
172.16.0.0/16192.168.1.1eth02
0.0.0.0/0 (默认)192.168.1.1eth0—
📌 工作流程：路由器收到一个数据包 → 看目的 IP → 在路由表里查 → 决定从哪个口转发 → 转发！整个过程毫秒级完成。

静态路由 vs 动态路由

📌 静态路由

  • 管理员手动配置路由表
  • 不会自动变化
  • 适合小型、固定网络
  • 简单、可控
  • 缺点：网络故障时不能自动绕路

🔄 动态路由

  • 路由器之间互相交换信息
  • 路由表自动更新
  • 适合大型、复杂网络
  • 智能、灵活
  • 常见协议：OSPF、BGP、RIP
🌍 互联网使用BGP(边界网关协议)在全球范围内动态选路；一个城市里通常用 OSPF。如果某条海底光缆被切断，路由会自动绕行，几秒内恢复通信。

3️⃣ 当某条网络线路突然故障，最能体现"动态路由"价值的现象是？
网络立即崩溃
数据包自动绕道
用户需要手动重启
IP地址改变
✅ 动态路由协议(如 BGP、OSPF)会自动发现故障并重新计算路径，让数据包绕开故障节点。这正是互联网"自愈能力"的体现。

🎓 课堂总结

  • 路由：为数据包选择传输路径的过程
  • 路由器：执行路由功能的网络设备，"包裹中转站"
  • 路由表：路由器的"地图册"，告诉它每个目的地从哪个口走
  • 路由算法：如最短路径(Dijkstra)，找到代价最低的路径
  • 动态路由：让互联网具备自愈能力，故障时自动绕路
