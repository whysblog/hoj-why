WWW = World Wide Web

万维网(WWW) 由蒂姆·伯纳斯-李 1989-1991 年发明，是建立在互联网之上的信息服务系统。

⚠️ 互联网 ≠ 万维网。 互联网是底层"路"，万维网是路上的"一种服务"。微信、邮件、游戏也跑在互联网上，但它们不属于万维网。

WWW 的三大基石

🏷️
HTML
超文本标记语言，规定网页的内容和结构。
🔌
HTTP
超文本传输协议，规定浏览器和服务器如何对话。
🔗
URL
统一资源定位符，给互联网上每份资源一个唯一地址。

URL 解剖

URL (Uniform Resource Locator) 就是网址。来看一个真实的 URL：

https://www.example.com:443/news/2024/article?id=42&lang=zh
部分含义例子
协议用什么"语言"交流http、https、ftp
主机名访问哪台服务器（域名）www.example.com
端口服务器上的哪个"门"80(HTTP) / 443(HTTPS)
路径该服务器上的哪份资源/news/2024/article
查询参数附加的请求条件?id=42&lang=zh

访问网页全过程

当你在地址栏输入 https://www.baidu.com 按下回车，背后发生了什么？

Step 1 · DNS 查询
把域名变成 IP
浏览器问 DNS 服务器："www.baidu.com 的 IP 是什么？" → 得到如 220.181.38.148。
Step 2 · TCP 连接
三次握手建立通信
浏览器和服务器进行 TCP 三次握手（HTTPS 还要 TLS 握手）。
Step 3 · 发送 HTTP 请求
浏览器："请给我这个网页"
发送一个 HTTP GET 请求，包含 URL、Header、Cookie 等。
Step 4 · 服务器响应
服务器返回 HTML
服务器返回状态码（200 OK）+ HTML 文档 + 资源链接。
Step 5 · 浏览器渲染
解析并展示页面
浏览器解析 HTML/CSS/JS，下载图片，最终把网页画到屏幕上。

HTML / CSS / JS 三剑客

📄
HTML · 骨架
规定网页"有什么"——标题、段落、图片、链接。类比：人的骨骼。
🎨
CSS · 皮肤
规定网页"长什么样"——颜色、字体、布局。类比：穿什么衣服。
⚡
JS · 行为
规定网页"能干什么"——点击、动画、表单。类比：动作和反应。
🛠 工具集里"HTML实时编辑器""CSS样式调试器""Markdown预览器"就是用这三种技术做的，可以亲手体验。

常见 HTTP 状态码

状态码含义常见场景
200 OK请求成功网页正常打开
301永久重定向网址变更
302临时重定向需要登录跳转
403 Forbidden禁止访问无权限
404 Not Found找不到资源网页删除/网址错误
500服务器内部错误后台代码出 bug
503服务不可用服务器维护/过载
💡 记忆窍门：2xx 成功、3xx 跳转、4xx 客户端错误、5xx 服务器错误。下次看到 404 你就知道"我访问的资源不存在"。

📝 课堂小测

1️⃣ 下列不属于万维网三大基石的是？
HTML
HTTP
URL
TCP
✅ 万维网三大基石是 HTML、HTTP、URL。TCP 是传输层协议，属于互联网基础，不是 WWW 特有。
2️⃣ 在 URL https://www.bilibili.com:443/video/BV1xx 中，443 表示？
协议版本
端口号
IP地址
文件大小
✅ 冒号后的数字是端口号。443 是 HTTPS 的默认端口。
3️⃣ 看到 "404" 状态码，最可能的原因是？
服务器爆炸
请求的资源不存在
账号被封
网速太慢
✅ 404 Not Found = 找不到该资源，通常是网址错误或资源已被删除。

🎓 课堂总结

  • 互联网 ≠ 万维网：互联网是底层，WWW 是一种服务
  • WWW 三基石：HTML（内容）+ HTTP（协议）+ URL（地址）
  • URL 五要素：协议、主机、端口、路径、查询参数
  • 访问流程：DNS → TCP → HTTP 请求 → 服务器响应 → 浏览器渲染
  • 状态码：2xx 成功、3xx 跳转、4xx 客户端错误、5xx 服务器错误
💭 课后任务：打开任意网站，按 F12 打开开发者工具的"网络"标签，刷新页面，观察实际的请求和状态码。
